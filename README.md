# 🚆 Smart Solar Rail Track Fault Detection System

## 📌 Overview

The Smart Solar Rail Track Fault Detection System is an AI-powered railway safety application that automatically classifies railway track images as **Defective** or **Non-Defective** using the YOLOv8 deep learning model.

The project also integrates a FastAPI-based web dashboard and an IoT sensor simulation for real-time monitoring of railway tracks.

---

## ✨ Features

- AI-based railway track defect detection
- YOLOv8 Classification Model
- FastAPI backend
- Interactive dashboard
- Image upload support
- Confidence score prediction
- Detection history
- IoT sensor simulation
- ONNX model export
